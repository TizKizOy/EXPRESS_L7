# API Документация

Этот документ описывает доступные маршруты и методы для взаимодействия с API приложения.

## Основные маршруты

### Покупатели (Customers)

- **Получение списка всех покупателей**
  - **Метод:** `GET`
  - **URL:** `/v1/customers`
  - **Описание:** Возвращает список всех покупателей.

- **Получение информации о конкретном покупателе**
  - **Метод:** `GET`
  - **URL:** `/v1/customer/:id`
  - **Описание:** Возвращает информацию о конкретном покупателе по его идентификатору.

- **Создание нового покупателя**
  - **Метод:** `POST`
  - **URL:** `/v1/customer`
  - **Описание:** Создаёт нового покупателя. Использует `body-parser` для обработки данных из тела запроса. Использует `uuidv4` для создания рандомного id.

- **Полное обновление данных покупателя**
  - **Метод:** `PUT`
  - **URL:** `/v1/customer/:id`
  - **Описание:** Обновляет все данные конкретного покупателя. Использует `body-parser` для обработки данных из тела запроса.

- **Частичное обновление данных покупателя**
  - **Метод:** `PATCH`
  - **URL:** `/v1/customer/:id`
  - **Описание:** Обновляет часть данных конкретного покупателя. Использует `body-parser` для обработки данных из тела запроса.

- **Удаление покупателя**
  - **Метод:** `DELETE`
  - **URL:** `/v1/customer/:id`
  - **Описание:** Удаляет конкретного покупателя по его идентификатору.

## Использование

Для использования API необходимо отправить HTTP-запросы к указанным выше маршрутам с соответствующими методами и данными в теле запроса (если требуется).
